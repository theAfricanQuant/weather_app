Which statement best describes eframe's update method in this app?

State flows into the screen

The app implements eframe::App. Its update method polls the worker channel, applies text scaling, draws the header, controls, results, animation, and history, then requests another repaint after 16 milliseconds so the animation moves smoothly.

This is immediate-mode UI: describe what the interface should look like for the current state each frame. The button interaction can change state; the next update draws the new state. For example, a result of None displays “No weather result yet,” while Some(result) displays the forecast.

Pythonista lens — render from state on every update: In many Python GUI frameworks you create widgets and then update individual widget properties as events arrive. This egui pattern asks the app to describe the screen again from its current state during update. A click changes state; the next frame reflects that change. The method receives &mut self, a mutable borrow of the app: it can update fields while Rust keeps track of who may read or change that app value at the same time. Treat this as a useful compiler clue, not punctuation to ignore.
