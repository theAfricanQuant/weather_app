# Mission: Build my first Rust project with a weather app as the guide

## Why
My goal is to use the weather app as a guide to learn how Rust projects are scaffolded and organized while I build my first Rust project. We begin with Cargo's generated files, then follow how the crate grows into modules, types, and features.

## Success looks like
- Create and run a binary crate, then explain what Cargo generated and why.
- Explain the roles of `Cargo.toml`, `src/main.rs`, crates, modules, and dependencies.
- Trace a weather lookup from input through validation, the worker thread, API parsing, rendering, and saved history.
- Make one small feature change and explain the Rust concepts involved.

## Constraints
- Follow the linked video and public repository as a guide; build our own first crate step by step rather than copying the finished app wholesale.
- Keep lessons short, practical, and beginner-friendly; use Nigerian metaphors when they clarify an idea.
- Keep lesson text, cards, and print output within consistent left and right margins.
- Prior Rust experience and operating system are not yet known.

## Out of scope
- Rebuilding the entire app from scratch in one lesson.
- Advanced async runtimes, meteorology, and production deployment.
