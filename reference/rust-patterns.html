Rust patterns in this app

A compact reminder. Use the linked lesson for the full explanation and practice.

Choose the type that says what is possible

  • Struct: several named fields belong together, such as a weather request's location and dates.
  • Enum: a value is one of several variants, such as LocationQuery::CityState or LocationQuery::Coordinates.
  • Option<T>: a value may be present as Some(value) or absent as None.
  • Result<T, E>: an operation may succeed with Ok(value) or fail with Err(error).

Follow the control flow

  • match: choose behavior by enum variant and handle each case explicitly.
  • ?: in a function returning a compatible Result, return early when an operation fails.
  • move closure: transfer ownership of captured values to the worker thread.
  • mpsc channel: pass a typed message from the worker back to the UI.

Keep API data at the edge

Serde deserializes JSON into private response structs. The weather service validates and normalizes those fields into the app's own types. If a measurement is missing, keep it as None; do not invent a zero.
